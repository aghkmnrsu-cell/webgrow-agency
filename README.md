# webgrow-agency

A modern agency landing page built with HTML, CSS, and JavaScript.

## Features
- Responsive navigation
- Hero section
- Services, about, portfolio, testimonials, FAQ
- Contact form UI
- Mobile-friendly design

## Run locally
Open `index.html` in a browser or use a local server.

## Customize
- Replace text with your own agency content
- Add project images in `assets/images`
- Connect the contact form to Formspree, Netlify Forms, or your backend
